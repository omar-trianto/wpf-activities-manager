# My WPF App

## Project Overview
Activities manager application to view, search, and manage activities.

## Features
- View activities
- Search for activities
- Create activities

## Installation
1. Clone the repo
2. Run `DB_Script.sql`
3. Open `activities-wpf.slnx`
4. Run the program
